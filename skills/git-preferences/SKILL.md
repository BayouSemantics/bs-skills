# Git Preferences

- use conventional branch naming prefixes (`feat/*`, `fix/*`, `chore/*`, `release/*`, etc)
- for new repos read [Repo Setup](references/repo-setup.md)
- before committing read [Commit Preflight Checks](references/commit-preflights.md)
- if asked to use a worktree read [Worktrees](references/worktrees.md)
- prefer squash merge
